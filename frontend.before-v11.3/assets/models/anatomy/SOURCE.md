# Anatomical GLB source

The vendored `heart.glb`, `lung.glb`, `liver.glb`, and `kidney.glb` files were
retrieved from the public `yihalem123/Human-Organ3D` repository at commit
`72863d9030cd6af1d49ddc11a9c5914c12465315` on 2026-08-08.

Upstream: https://github.com/yihalem123/Human-Organ3D

The upstream README states: "This project is open source and available under
the MIT License." The models are redistributed here solely for the interactive
research-demonstration viewer. Preserve this source notice when redistributing
the bundled assets.

The OncoTwin application remains a research demonstration and does not claim
that these meshes are diagnostic or patient-specific anatomy.
