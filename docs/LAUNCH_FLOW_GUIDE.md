# Launch Flow Guide

OncoTwin opens with a six-step visual walkthrough that follows a governed signal through the real application views:

1. **Signal** — synthetic research incident and grounded context.
2. **Recall** — durable CockroachDB patient, event, checkpoint, handoff, and approval memory.
3. **Branch** — a tandem agent council produces memory-conditioned evolution paths.
4. **Observe** — the 3D genome helix separates observed generations from projections.
5. **Prove** — official CockroachDB MCP, ccloud, Agent Skills, vector memory, and proof receipts.
6. **Gate** — a human safety boundary prevents autonomous clinical action.

The walkthrough automatically appears on first launch. Completion is stored only in browser `localStorage`; no user identity or telemetry is recorded. It can always be replayed with **How it works** in the header.

Keyboard controls: use Left/Right Arrow to move between steps and Escape to close.
