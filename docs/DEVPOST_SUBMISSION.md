## The problem

Cancer research ML pipelines join cohort, single-cell, genomic, protein and spatial evidence. A silent NULL, stale feature, schema mutation or provenance gap can propagate into scores and visualizations. An LLM cannot safely repair such a pipeline from table names alone: it needs canonical schemas, lineage, ownership, queries, quality and governance context.

## The solution

OncoTwin 3D turns DataHub context into an interactive safety control system. A judge triggers one of seven synthetic cancer-data failures and watches six collaborating agents retrieve live DataHub evidence, build a digital-twin risk state and choose a safety action. The flagship Biomarker Completeness Crisis raises a real DataHub incident, proves the downstream score-table blast radius, blocks model consumption, generates schema-grounded BigQuery SQL, pauses for human approval, repairs and validates the feature product, resolves the incident, then writes a receipted recovery record back to DataHub.

## What the agents actually change

After explicit human approval, the flagship workflow:

1. rebuilds `progression_features` using catalog-compatible `COALESCE` logic;
2. regenerates `progression_scores`;
3. writes a `PASS` quality event;
4. resolves the associated DataHub incident;
5. writes an `AgentRepaired` tag;
6. writes responsible agent, timestamp, job IDs, validation status and receipt hash into DataHub properties;
7. verifies inherited knowledge with an MCP read-after-write.

## How DataHub is used

- Self-hosted MCP Server: search, entities, schema, upstream/downstream lineage and dataset queries
- Context graph: canonical identity and blast-radius discovery
- Agent Context Kit + LangChain: evidence-grounded ML safety reasoning
- DataHub Skills: search → quality → lineage → repair workflow
- Incidents: active-to-resolved governed lifecycle
- Official REST emitter: durable description, tags and custom properties
- Analytics Agent integration: grounded natural-language analytics
- BigQuery ingestion: schema, profiles, usage, queries and fine-grained lineage

## Originality

OncoTwin does not recreate a metadata catalog. It transforms DataHub's context graph into a visible, replayable 3D safety mechanism. Metadata becomes an operational digital-twin state; lineage becomes a blast-radius animation; incidents become agent constraints; and governed writeback becomes inherited organizational memory.

## Real-world usefulness

The same design applies to regulated ML feature products beyond oncology: fraud, finance, manufacturing and supply chains. Platform teams can stop unsafe consumers, generate schema-compatible repair artifacts and retain evidence of why a recovery was approved.
